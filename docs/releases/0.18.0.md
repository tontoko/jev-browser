# Jev Browser 0.18.0

This minor release runs the SDK inside Cloudflare Workers, Durable Objects and Agents
with Cloudflare Browser Run. It has no breaking changes to the exported API.

## Upgrading from 0.17.0

No code or configuration change is required for Node, the CLI or MCP.

- **`@tontoko/jev-browser/workers`.** `launchBrowserRun(env.BROWSER, options)` opens a Browser Run
  browser through its binding and `@cloudflare/playwright` (add it to the Worker; it is an optional
  peer dependency) and returns `{ browser, sessionId }`. Options are the SDK's `JevBrowser` options
  plus `recording`, `keepAlive` and `contextOptions` (for example a viewport). Closing the JevBrowser
  closes the Browser Run browser. `attachBrowserRunPage(page, options)` attaches a page you opened
  yourself. Enable `nodejs_compat` in the Worker.
- **Import-safe in workerd.** Nothing reads package files at import, `playwright-core` is loaded only
  by `JevBrowser.launch()`, and page functions are sent as source text (Workers forbid `new Function`).
- **Cancellation on Browser Run.** `@cloudflare/playwright` 1.3.6 is based on Playwright 1.58.2 and
  ignores AbortSignal options, so on Browser Run cancellation is bounded by Jev's own deadlines.
- The internal `playwrightCoreVersion` is now a function (it was a string constant).

## Installation

```sh
npm install --save-dev https://github.com/tontoko/jev-browser/releases/download/v0.18.0/tontoko-jev-browser-0.18.0.tgz
npx jev-browser install chromium
```

For Workers, also `npm install @cloudflare/playwright`.

npm 7+ and pnpm install the `playwright-core` and `zod` peers automatically;
with Yarn Berry, add them explicitly:
`yarn add -D ./tontoko-jev-browser-0.18.0.tgz playwright-core zod`.

This is GitHub Release tarball distribution, not an npm registry publication.
Verification and recovery follow the 0.10.0 notes: publication happens from CI
only after every platform job succeeds and never overwrites an existing tag.
