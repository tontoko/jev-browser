# Jev Browser 0.17.0

This minor release adds optional HTTP headers when attaching over CDP or WebSocket.
It has no breaking changes.

## Upgrading from 0.16.0

No code or configuration change is required. Existing `cdpEndpoint` / `wsEndpoint`
attach without headers behaves as before.

- **`cdpHeaders`.** Pass a string map on `JevBrowser.launch()` or in `--options-file`
  JSON. When set, attach uses Playwright's object form
  `connectOverCDP({ endpointURL, headers })` or `connect({ wsEndpoint, headers })`.
  Typical use is Cloudflare Browser Run `Authorization`. Values are redacted from
  screen evidence and are not part of the session options hash (same idea as
  `apiKey`), so rotating a token does not force `SESSION_MODE_MISMATCH`.

## Installation

```sh
npm install --save-dev https://github.com/tontoko/jev-browser/releases/download/v0.17.0/tontoko-jev-browser-0.17.0.tgz
npx jev-browser install chromium
```

npm 7+ and pnpm install the `playwright-core` and `zod` peers automatically;
with Yarn Berry, add them explicitly:
`yarn add -D ./tontoko-jev-browser-0.17.0.tgz playwright-core zod`.

This is GitHub Release tarball distribution, not an npm registry publication.
Verification and recovery follow the 0.10.0 notes: publication happens from CI
only after every platform job succeeds and never overwrites an existing tag.
