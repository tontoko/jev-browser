# Jev Browser 0.16.0

This minor release adds opt-in itemized screen judging with image-capable decision models.
It has no breaking changes.

## Upgrading from 0.15.1

No code or configuration change is required. The text-only decision engine, `screenDecide`
and every existing command behave as before.

- **`screenJudge` and the `judge` option.** Capture the viewport once and send it, with the
  page's visible text (default), HTML or nothing, and up to 64 positively phrased yes/no items
  in one request to an image-capable System One-compatible model: a Workers AI run URL, a
  System One API root, or your own adapter. Every item gets a probability and passes at or
  above its threshold (judge, request or item level; default 0.5). See
  [screen judging](../screen-judge.md).

## Installation

```sh
npm install --save-dev https://github.com/tontoko/jev-browser/releases/download/v0.16.0/tontoko-jev-browser-0.16.0.tgz
npx jev-browser install chromium
```

npm 7+ and pnpm install the `playwright-core` and `zod` peers automatically;
with Yarn Berry, add them explicitly:
`yarn add -D ./tontoko-jev-browser-0.16.0.tgz playwright-core zod`.

This is GitHub Release tarball distribution, not an npm registry publication.
Verification and recovery follow the 0.10.0 notes: publication happens from CI
only after every platform job succeeds and never overwrites an existing tag.
