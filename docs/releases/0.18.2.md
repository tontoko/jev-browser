# Jev Browser 0.18.2

This patch release gives the actor one more decision when it chooses to submit a form before
filling it. It has no breaking changes.

## Upgrading from 0.18.1

No code or configuration change is required.

- **A premature submission is sent back once.** When the actor chooses a `commit` action while the
  native form is still invalid, or while supplied current-stage inputs are unapplied, and the form
  offers a way to fill them, `run` does not execute the submission. It sends the same screen back for
  one more decision. That decision state carries `submitRefused`: `{ form: 'invalid' }` for a goal
  whose quoted values are fill candidates, or `{ inputs: [paths] }` for `values` that are not yet
  bound. Any performed step clears it.
- **A second premature submission still stops.** If the actor chooses to submit again with no step
  in between, `run` returns `stopped / missing-input` as before. No mutation is retried.

## Installation

```sh
npm install --save-dev https://github.com/tontoko/jev-browser/releases/download/v0.18.2/tontoko-jev-browser-0.18.2.tgz
npx jev-browser install chromium
```

For Workers, also `npm install @cloudflare/playwright`.
